# Password Generator

## Project Description
This Python project generates random passwords to help users create stronger passwords.

## Features
- Generates random passwords.
- Allows users to create passwords of different lengths.
- Uses letters, numbers, and special characters.

## Technology Used
- Python

## How to Run
1. Install Python.
2. Open `Password_generator.py`.
3. Run the program.
4. Enter the required password length when prompted.

## Purpose
This project demonstrates basic Python programming, random generation, and string handling.
